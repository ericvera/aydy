VS Code window tabs: unread count

The owner's setup: "window.nativeTabs": true, one window per git worktree, each window a native macOS tab. The tab label is the window title, which the extension writes into a generated .code-workspace file outside the repo. Format: ● N folder for two to nine unread sessions, ● 9+ folder for ten or more, ● folder for one, ○ folder for none. The folder name is written as literal text, so no (Workspace) suffix appears.
